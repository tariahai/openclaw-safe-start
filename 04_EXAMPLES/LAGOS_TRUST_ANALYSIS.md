# Example: Lagos Trust Analysis
### OpenClaw Governance Framework | Tariah AI | 04_EXAMPLES

## Purpose

This document demonstrates a complete governed OpenClaw task execution using a real-world use case: analyzing trust signals for online buyers and sellers in Lagos, Nigeria. It shows how the governance framework operates in practice — from task submission through classification, execution, and output — without modifying any external system.

This example is READ_ONLY throughout. No authorization is required.

---

## Context

Igbigi is a platform that helps buyers and sellers in Nigeria's informal economy transact with confidence. A core feature is trust signal analysis: given a seller's profile, transaction history, and behavioral data, produce a structured trust assessment that the buyer can use to make an informed decision.

This is a Class 002 (Analysis and Synthesis) task. It reads available data, processes it, and produces a recommendation. No external data is written or modified.

---

## Task Submission

```
TASK: Analyze the trust signals for seller ID SLR-00442 and produce a
      structured trust assessment with a confidence score and
      recommendation for a buyer considering a ₦45,000 transaction.

CLASS: CLASS 002 — Analysis and Synthesis
INPUT: Seller profile, transaction history, behavioral flags for SLR-00442
OUTPUT: Structured trust assessment in JSON format
```

## What This Example Demonstrates

### 1. Task classification is explicit
The agent confirms the task class before proceeding. A reader reviewing the audit log can immediately see that this was a Class 002 task and that READ_ONLY mode was correct.

### 2. Output is a recommendation, not a decision
The assessment produces a confidence score and a recommendation. The final decision — whether to proceed with the transaction — is explicitly returned to the buyer. The agent does not make the transaction decision.

### 3. Scope is respected
The agent analyzed seller ID SLR-00442. It did not access any other seller records. It did not write to the seller's profile. It did not modify the trust score in the database. The analysis exists in the response context only.

### 4. Uncertainty is surfaced
The agent surfaces the absence of buyer reviews and the transaction value variance as explicit risk factors rather than absorbing them into a higher confidence score. Honest uncertainty is a governance requirement, not just a product feature.

### 5. Audit trail is complete
The task ID links the submission to the classification event, the analysis, and the output in the audit log. If this assessment were later reviewed — for a dispute, a compliance audit, or a product improvement analysis — the full trace is available.
